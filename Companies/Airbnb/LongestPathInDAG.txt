Problem : Longest Path in a DAG

You are given a directed acyclic graph (DAG). Each node v has a score w(v). Each directed edge 
(u→v) has a nonnegative time cost t(u,v). There is a unique start node literally named "start" 
with w(start)=0. A terminal node is any node whose name begins with an underscore "_". You may 
traverse edges only in their given direction. For any path P from "start" to any terminal node, 
define its total score as Score(P) = (sum of w(v) over all nodes v on P) − (sum of t(u,v) over 
all edges on P). Compute the maximum Score(P) across all such paths and return both this maximum 
value and one corresponding optimal path (as an ordered list of node names). If no terminal is 
reachable from "start", indicate that no feasible path exists. Describe your algorithm and analyze
its time and space complexity.

You have a DAG where:

1. Nodes have scores w(v) — you gain points for visiting them
2. Edges have time costs t(u,v) ≥ 0 — you lose points for traversing them
3. You start at "start" (with w(start) = 0)
4. You want to reach any node whose name begins with "_"

For a path start → v1 → v2 → ... → vk where vk is a terminal, the score is:

Score = w(start) + w(v1) + ... + w(vk)
      - t(start→v1) - t(v1→v2) - ... - t(v(k-1)→vk)
Since w(start) = 0, you're summing up all node scores along the way, then subtracting all edge costs.


Key Insight: Edge Transformation

To simplify, you can fold the node scores into the edges. Define a modified edge weight:
w'(u → v) = w(v) - t(u, v)
This converts the problem into a standard longest path on a DAG — you just maximize the sum of w' 
over all edges on the path (starting from "start" which contributes 0).
